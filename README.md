# V5.3 Safe Orders

1. Supabase SQL Editor'de `supabase.sql` dosyasını çalıştırın.
2. Vercel environment variables: `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `ADMIN_PASSWORD`.
3. GitHub'a tüm dosyaları yükleyin; Vercel deployment tamamlanınca siteyi yenileyin.
4. Sipariş formu artık ödeme/kart bilgisine benzeyen alanları toplamaz. Başvuru kaydı admin paneline düşer ve kullanıcıya stok bulunmadığına dair kurumsal sonuç ekranı gösterilir.
